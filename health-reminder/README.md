# Health Reminder

一个用于健康使用电脑的 Noctalia 插件。

## 功能

- Bar Widget，点击可打开面板
- Panel 面板，查看提醒状态并执行快捷操作
- 可分别设置久坐提醒和喝水提醒的分钟间隔
- 使用 toast 推送提醒
- 支持暂停、恢复、重置计时和测试提醒

## 说明

插件会在后台根据设置的时间间隔检查是否需要发送提醒。

- 久坐提醒默认每 45 分钟触发一次
- 喝水提醒默认每 30 分钟触发一次

## 测试

1. 在 Noctalia Shell 中启用插件
2. 打开插件设置，调整提醒间隔
3. 使用面板中的“测试久坐提醒”和“测试喝水提醒”确认 toast 正常弹出
4. 使用“暂停提醒”和“恢复提醒”确认状态切换正常
